## About

**FitSync** is a comprehensive fitness tracking application built with **Next.js 15** and **TypeScript**, backed by **PostgreSQL** via **Prisma ORM**. It combines workout logging, nutrition tracking, and progress analytics with an AI-powered fitness coach running on **Google Gemini 2.5 Flash** — all in a responsive, full-stack Next.js app.

## Features

- Workout logging with exercise tracking and session history
- Daily nutrition and calorie intake logging
- Progress monitoring with visual analytics
- AI fitness coach powered by Google Gemini 2.5 Flash for personalized workout and nutrition advice
- Secure authentication via NextAuth.js with bcrypt password hashing
- Protected dashboard and chat routes with middleware-enforced sessions
- Responsive UI that works across desktop and mobile

## Technology Stack

- **Frontend**: Next.js 15, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma ORM
- **Database**: PostgreSQL (Neon)
- **Auth**: NextAuth.js
- **AI**: Google Gemini 2.5 Flash
