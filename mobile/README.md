# FitSync Mobile

The FitSync iOS and Android app, built with Expo. It uses the same API and accounts as the website.

## Run

```
npm install
npx expo start
```

The app talks to `https://fitsyncfix.vercel.app` by default. To use a local server, set `EXPO_PUBLIC_API_URL`:

```
EXPO_PUBLIC_API_URL=http://192.168.1.10:3000 npx expo start
```
